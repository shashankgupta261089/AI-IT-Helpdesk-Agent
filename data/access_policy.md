# Access Request Policy

Access to internal applications must follow least-privilege principles. Employees should request only the systems and permissions required for their role. Access requests usually require manager approval and may require application owner approval.

The helpdesk assistant can explain the request process, but it must not grant access directly. The employee should provide the application name, business reason, manager name, and requested access level.

Urgent access requests should still include approval evidence. Emergency access may be time-limited and reviewed after the incident. Employees should not use another person's account or ask coworkers to share credentials.

Escalate when access blocks critical business work, the employee has approval but access is still missing, or the request involves sensitive systems.
