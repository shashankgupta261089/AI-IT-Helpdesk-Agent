# Outlook Troubleshooting Guide

Outlook issues are often caused by cached credentials, add-ins, large mailboxes, or temporary service problems. First ask the employee whether Outlook on the web is working. If Outlook on the web works, the problem is likely limited to the desktop client.

Ask the employee to restart Outlook. If that does not help, restart the computer and try again. If Outlook opens but behaves slowly, disable recently added add-ins and check whether search or send/receive improves.

If Outlook repeatedly crashes, ask the employee to open Outlook in safe mode and remove the most recent add-in. Employees should not delete mailbox data unless instructed by IT.

Escalate when Outlook is unavailable for many users, the employee cannot access email before urgent work, or troubleshooting does not restore access.
